JS CATERER WEBSITE — VIDEO SETUP INSTRUCTIONS
==============================================

To add a loopable video background to the homepage hero:

1. Place your video file in this folder:
   → assets/videos/hero_bg.mp4

2. The hero section already references this file:
   <video ... poster="assets/wedding_feast.jpg">
     <source src="assets/videos/hero_bg.mp4" type="video/mp4">
   </video>

3. Video tips for best results:
   - Format: MP4 (H.264 codec)
   - Duration: 15–30 seconds (loops seamlessly)
   - Resolution: 1920×1080 or higher
   - File size: Keep under 10MB for fast loading
   - Content: Kitchen prep, food close-ups, serving scenes

4. If NO video file is present:
   → The 6-image slideshow (wedding_feast, live_kitchen,
     corporate_buffet, temple_annathanam, banana_leaf_serving,
     sweets_live_counter) auto-plays at full opacity.

5. If a video IS present but fails to load:
   → Slideshow automatically takes over at full opacity.
